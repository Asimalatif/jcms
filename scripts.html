Open the app

New laptop: set everything up again

  1. Install Google Chrome (or Edge) and the Tampermonkey extension from the Chrome Web Store.
  2. Open chrome://extensions, switch on Developer mode, open Tampermonkey's Details and turn on Allow user scripts (new Chrome versions need it).
  3. Press Install below on every script you use; Tampermonkey shows its page: press Install again.
  4. Log in to the UOP portal and open Student → Students: the panels appear.
  5. Portal Sync, New Session List and Enrollment Manager ask once for the sync key (app → College → UOP portal sync → Get sync key). When Tampermonkey asks to connect to script.google.com, press Always allow.
The sync key is not stored in these files (the code is public on GitHub). The same files and these notes are in GitHub: Asimalatif/jcms → PORTAL-SCRIPTS.md. To update a script on a laptop, press Install again.

1. JCW Portal Sync v1.12

Read only on the portalSends to JCMS

Reads every Jinnah College student from the portal and fills the empty cells of Transform-ALL-COLLEGE-STRENGTH; lists students who left for Left Students.

  • Quick sync (1–2 min): the list, plus fee challans and details of new enrolled students. Auto quick sync every 20 min while the tab is open; the app's “Sync with the portal now” starts it by itself.
  • Full sync (30–60 min, resumes after a logout): DOB, contact, email, photo, HQ, quota, matric board / year / roll no / marks, challans, FEE PAID DATE, First Challan Date, 1st and 2nd year subjects.
  • Details of students who left; Move / Add N to Left Students only when you press it.
  • v1.12 adds First Challan Date (finds migrated-in students). If a laptop still has 1.11, install again.

2. JCW New Session List v2.1

Read only on the portalReads Seat settings from JCMS

Makes the next session's 1st Year list as Excel in the exact Transform columns: F.A, Pre-Engineering, FCS, Pre-Medical (S), (M), (E), “Seats & merit” and “Check these”, by every admission rule (manual sections 20A and 20C).

  • Panel: session, Enroll# year, first S.No, last date, seats (From the app), subsidized fee, Evening, fee date corrections, batch.
  • 1. Read the list → 2. Read details & make the Excel file (20–40 min for 1,200 students; Resume after a logout).

3. UOP VC – Enrollment Manager v3.7

Changes the portalWrong values from JCMS

Sets Enrollment#, Reg# (= Enrollment#), Program, Class, Section and matric / O-Level marks on each student's portal edit page.

  • ⬇ Load wrong values from JCW app (Admissions → Wrong on portal) or a CSV (PORTAL ID, Enroll#, Program, Class, Section, Student Name, Father Name).
  • Always 🔍 Check only first, then ▶ Update. It never saves when the student's name on the page is different; ⚠ rows are unticked; “✕ never change this student”; ⬇ Report (CSV).
